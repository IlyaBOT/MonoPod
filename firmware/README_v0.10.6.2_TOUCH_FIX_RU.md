# MonoPod v0.10.6.2 — кнопки и Touch ESP32-S3

- GPIO9: `INPUT`, обязательный **внешний** 10 кОм от GPIO9 до 3.3 В. Кнопки подключаются к GND через 0 / 5.1k / 10k / 20k / 39.9k (MENU / PREV / NEXT / PLAY / SELECT).
- Номинальное напряжение на GPIO9 при нажатии: 0 / 1115 / 1650 / 2200 / 2640 мВ. На ненажатом GPIO9 — около 3300 мВ.
- На старте Touch выполняет 48 циклов прогрева, затем калибрует 32 измерениями. Если стартовая база в несколько раз отличается от текущих значений, через четыре опроса выполнится новая калибровка. Перед включением и командой `$TOUCH_CAL` убрать палец с колеса.
- Реальные диагностические данные показывали базу 160k–814k при RAW 30k–39k, поэтому DETECT всегда был NO.
- Для проверки в UART: `$TOUCH_CAL`, затем `$TOUCH`. Для отслеживания `$TOUCH_DEBUG=1`. Корректный DELTA в покое около нуля, под пальцем положительный.
- Измерить реальное напряжение каждой кнопки через `$BUTTONS_DEBUG=1` (если доступно) и при необходимости уточнить `BUTTON_ADC_WINDOWS_MV` в `Config.h`.
- По фактическим замерам установлено `TOTAL=2%` по умолчанию вместо 10%, иначе отдельный электрод не проходит вторую проверку даже после корректной калибровки. `SENS=10%` оставлен.
