# MonoPod v0.10.6.3 — корректировка Touch Wheel

Основной профиль ESP32-S3, электродная последовательность GPIO1,2,5,6,7,8.

- SENS по умолчанию 3% вместо 10% (остальные настройки через UART сохраняются). При 10% GPIO8 с DELTA=3947 и BASE=34011 давал только 546 взвешенных единиц, что недостаточно для уверенного обнаружения перехода.
- DOM по умолчанию 45% вместо 50%; TOTAL остаётся 2%, MIN=5.
- Начало трекинга после 35 мс вместо 90 мс.
- Разрывы распознавания до 130 мс не уничтожают трекинг. После длительного провала или большого скачка угол переустанавливается без прокрутки.
- Расширен допустимый шаг угла до 1.6 рад за цикл и снижен порог мелкого дрожания до 0.08 рад.
- GPIO9 по-прежнему INPUT с внешней подтяжкой 10 кОм на 3.3 В.

## Проверка

1. Убрать руку с колеса, выполнить `$TOUCH_CAL`.
2. Включить `$TOUCH_DEBUG=1` и сделать два медленных полных оборота в обе стороны.
3. Не менять SENS между проверками: сейчас начальное значение 3%.
4. После отпускания пальца убедиться, что DETECT=NO, а через >130 мс TRACK=NO.

Arduino ESP32-S3 на физическом устройстве не проверялось.
