# MonoPod v0.10.6.4: кнопки GPIO9, внешняя подтяжка 20 кОм

**Аппаратно:** заменить физический резистор между GPIO9 и 3.3 V с 10 кОм на **20 кОм**. Это изменение прошивки не изменяет сопротивление уже установленного резистора. Внутренняя подтяжка по-прежнему отключена (`INPUT`, `BUTTON_ADC_INTERNAL_PULLUP=false`). Для GPIO21 HOLD остаётся отдельная внешняя подтяжка 10 кОм. Профиль классического ESP32 не менялся.

Проверенные значения `$BUTTON_ADC` при новой схеме (мВ): MENU 0; PREV 654–657; NEXT 1064–1085; PLAY 1604–1702; SELECT 2194–2217. Наблюдавшиеся 3148 мВ во время PLAY могут означать отпускание/переходный процесс или плохой контакт. Это значение **не** распознаётся как PLAY.

Окна распознавания GPIO9 (мВ):

| Кнопка | Минимум | Максимум |
|---|---:|---:|
| MENU | 0 | 120 |
| PREV | 530 | 800 |
| NEXT | 940 | 1220 |
| PLAY | 1480 | 1840 |
| SELECT | 2040 | 2410 |

Окна разнесены: напряжения в промежутках и напряжение отпущенных кнопок не распознаются. Для проверки удерживайте кнопку и выполните `$BTNS_ADC=1`, затем `$BTNS_ADC=0`; проверьте также спокойное состояние GPIO9. В старых README есть сведения для предыдущих аппаратных ревизий.
