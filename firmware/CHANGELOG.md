# MonoPod S3 DevTest v1

Независимая от основной прошивки версия, отдельная диагностическая среда:
- Один 896 Гц / 110 мс сигнал на пьезе GPIO42 при старте.
- Вращающийся wireframe 3D cube + фактический FPS на ST7735 160×128.
- SPI microSD: повторная инициализация каждые 5 с, успешная запись `SD-Card_init-success.txt`, после успеха отсутствие дальнейшего обращения к карте.
- I²S PCM5102A 16-бит stereo без ESP8266Audio и микшера.
- YMODEM CRC16 над UART0, 1-KiB блоки, проверка CRC, повторов, двойной EOT, итоговый empty block.
- PSRAM audio store, предел из крупнейшего свободного блока с резервом 128 KiB; сырые PCM16LE mono/stereo, 8–48 кГц.
- Чёрный/красный RECEIVE экран, блокировка всех прочих задач во время RX; воспроизведение один раз, I²S выключается и PSRAM освобождается.
- `tools/send_audio_ymodem.py` с ffmpeg конвертацией и генератором встроенного тестового тона.
- Диагностика ADC GPIO4 и микрокарты через UART.
