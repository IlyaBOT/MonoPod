# MonoPod v0.9.0 (candidate, compile and hardware tests pending)

## Source changes
- Inverts `TFT_BL_ACTIVE_LOW=false` for the ESP32-S3 direct-LED prototype. **Hardware risk: 30 mA on an ESP32-S3 output may exceed safe continuous drive; recommended an external transistor.**
- Volume 0..100 clamped, no wraparound, moved to Now Playing. Wheel cadence <=110ms uses 10%, slower turns 1%. Real touch wheel sampling and event cadence determine subjective acceleration.
- Select enters seek control; wheel scrolls scrub preview. On 350ms pause seek for MP3/WAV is attempted using decoder restart and byte-position seek (MP3 frame resync approximate); on 5s idle overlay returns to progress. Select commits immediately.
- Full-screen 16-bit GFXcanvas16 framebuffer for S3 menus; transfer once to TFT avoids visible full-screen clear in menu redraw. Now Playing bottom-only progress/volume/time updates.
- Now Playing has ordinal and total song count, 3 metadata lines with ellipsis, elapsed and remaining times. Track duration uses ID3 TLEN, Xing/Info, WAV RIFF, or CBR bitrate estimates, thus VBR without Xing may not be exact.
- Battery sampled every 60s (or at boot); status icon repainted only when 25% charge band changes (0,1,2,3,4 bars).
- Boot logo drawn on startup; optionally load color `160x128 RGB565LE /MonoPod/boot.rgb565` converted via `tools/pack_bootlogo.py` and stored on SD. Built-in bitmap-like Apple-inspired icon is NOT a ripped Apple firmware image.
- Bad Apple menu on S3 by default, excluded from original ESP32 at preprocessing (`EXCLUDE_BAD_APPLE_EASTEREGG`). 2-bit grayscale 160x128 delta-RLE BAV1 player, <=25fps, sourced from microSD or opt-in PROGMEM `BadAppleEmbedded.h` generated by the converter. **MP4 not available in this chat runtime, so no Bad Apple frames are bundled.** The default 3MB APP partition is likely too small for an entire embedded video; change partition before opting into PROGMEM.
- The existing SD FAT formatting, sync protocol, Wi-Fi restore and dev console remain.

## Limitations/validation
- No physical compile with Arduino-ESP32 3.3.12 or TFT/PCM5102A/SD, so do not mark as stable.
- No exact sample-accurate VBR or AAC/FLAC seeking; precise MP3 seeking requires decoder frame/index verification.
- Streaming Bad Apple is benchmarked by user device only; 15fps suggested for shared SPI, not guaranteed.
- SPI TFT drawing performance may depend on Adafruit ST7735 library version and canvas allocation.
