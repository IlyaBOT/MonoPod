# MonoPod v0.8.9.3 — Classic 4G mono UI, settings, FAT formatting, Click Wheel tick

Based on firmware v0.8.9.2 and the user's screenshots and uploaded `iPod_4.3.1.1.ipsw` (Apple iPod 4th-gen monochrome, firmware 3.1.1). No Apple firmware bytes are distributed.

## Functional changes

- Center status-bar titles on the physical 160x128 display, preserving outer Wi-Fi/hold + battery indicators. Truncate by **rendered glyph width**, with `...`, not raw byte count (handles UTF-8).
- Truncate long list-row labels without covering submenu arrows. Avoid full redraw on Wi-Fi RSSI icon changes.
- Settings menu reordered closer to iPod 4G (`About`, `Shuffle`, `Repeat`, `Backlight Timer`, `Clicker`, `Contrast`, `Reset All Settings`), with MonoPod-only Wi-Fi, Bluetooth (classic ESP32 only) and microSD additions. Brightness and Font Smoothing are MonoPod additions.
- Backlight Timer uses reference screenshots' Off / 1 / 2 / 3 / 5 Seconds / Always On list. Note: firmware 4.3.1.1's English string table contains Off / 2 / 5 / 10 / 20 Seconds / Always On; screenshot and IPSW do not agree. This build intentionally follows the screenshot for the on-screen list.
- `Reset All Settings` has Cancel/Reset choices; applies volume, clicker route, backlight brightness and palette immediately. Only MonoPod UI settings are reset, not the Wi-Fi credentials stored in a different NVS namespace, not the SD card.
- `About` scrollable menu shows songs, capacity, free space, version, device GUID and model.
- Software click events are exclusively `Key::Up` and `Key::Down` generated by a wheel (or UART virtual scroll). No software click on Menu, Select, Previous, Next, or Play.
- Replaced pitched headphone click with a short, decaying pseudorandom PCM pulse. Local piezo plays a 2ms click-like pulse, not a sustained beep.
- I²S idle output drains 256 zero frames and stops the physical output, reinitializing it on the next click. This is a mitigation for repeated last-DMA-buffer audio; needs validation on PCM5102A hardware.
- Enabled **SdFat v2** FAT16/FAT32 formatting. Entire microSD contents are irreversibly erased after two independent Select confirmations from microSD → Format Card. Format supports an unformatted card; remounts with Arduino `SD`, creates `/Music` and `/Playlists`, then reindexes. Larger SDXC cards get FAT32 for Arduino-SDFS compatibility (nonstandard for SDXC); test with a backed-up card first.
- Does **not** generate `/iPod_Control` or `iTunesDB`, as USB iTunes mode is not implemented.

## Dependencies and build

Arduino-ESP32 3.x, Adafruit ST7735/GFX, ESP8266Audio, **SdFat by Bill Greiman version 2.x**. In Arduino IDE, use Library Manager: `SdFat` (Greiman). Without it, the now-enabled formatter will cause a *compile error*, rather than silently hiding the Format option. Optional BT stack is still excluded from S3 compilation.

Flash 16 MB, OPI PSRAM 8 MB, USB CDC On Boot enabled for ESP32-S3 Native USB sync. GPIO assignments and SD SPI speed (4 MHz) unchanged.

## Tests

- `PYTHONPATH=. pytest -q`: 59 passed (includes 4 added v0.8.9.3 regression tests).
- Native C++ mixer test: compiled and passed with an AudioOutput stub. Verifies that the short click terminates, I²S stops in idle, and subsequent triggers reopen the output.
- **Not** compiled against the user's full Arduino-ESP32 3.3.12 toolchain and not tested on actual hardware. Confirm SdFat compatibility and SD mounting after formatting before use with valuable media.

## Focused on-device validation

1. Verify old media library still mounts and plays without formatting.
2. Change Settings → Clicker Off/Speaker/Headphones/Both; scroll with `$UP`/`$DOWN` via UART, inspect both piezo and PCM5102A output. Check silence after each tick, and zero tick sounds on `$MENU`, `$SELECT`, `$NEXT`.
3. Change brightness, volume, contrast, backlight timer, and reset: verify changes appear **without reboot**.
4. Verify centered/ellipsized title and About values.
5. **Only with expendable backed-up SD**: microSD → Format Card → SELECT → SELECT, then ensure card mounts and `/Music` + `/Playlists` exist. Test both blank and FAT32 cards.
