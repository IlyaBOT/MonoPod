# MonoPod v0.10.6.1 — калибровка верхней точки батареи / индикация зарядки

Основа: v0.10.6 NEXT 5K1 + компактный S/N + условное Now Playing + исправление `bigEndian4()`.

- По измерениям прототипа: 4,23 В на аккумуляторе = 2,10 В на GPIO4; коэффициент `BATTERY_ADC_RATIO = 4.23/2.10` (вместо 2.0). Верхняя точка кривой SoC = 4,23 В. Нижний диапазон пока не перенастроен.
- `BATTERY_CHARGE_ADC_ON_MV=2150`: состояние `Charging` включается **строго выше 2,15 В** на GPIO4. `BATTERY_CHARGE_ADC_OFF_MV=2130`: выключается ниже 2,13 В для гистерезиса. Считывание при старте и раз в 60 секунд.
- На TFT режим зарядки рисуется как полная батарея с молнией, имеет приоритет над обычными 0–4 сегментами. Иконка обновляется без перерисовки всего экрана, при отключённой подсветке не зажигает её.
- Команда UART0 `$BATTERY` теперь дополнительно показывает `ADC=...mV CHARGING=YES/NO`.
- Версия изменена в startup banner, About и MPOD1/Wi-Fi info JSON на `0.10.6.1`. Протокол MPOD1 v4 не менялся.

**Ограничения и безопасность:** порог GPIO4 2,15 В эквивалентен примерно **4,33 В батареи** для измеренного делителя; при 4,23 В (GPIO4 2,10 В) иконка зарядки **не включится**. Напряжение само по себе не доказывает наличие зарядного тока; для достоверного статуса лучше использовать выход CHRG/STAT микросхемы зарядки (с согласованием уровней). Порог зарядки не заменяет защиту Li-ion от перезаряда.

Проверки: `pytest -q tests`, нативный тест `tests/battery_charge_native_test.cpp`, компиляция Arduino для ESP32-S3 *не проверена*.
