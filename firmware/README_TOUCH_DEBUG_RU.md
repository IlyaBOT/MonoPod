# MonoPod v0.10.6.1 — диагностика Touch Wheel

**Версия прошивки не менялась.** Нужная плата: ESP32-S3 N16R8, Arduino-ESP32 3.3.12.

## Что изменено

- Отладка шести сенсорных входов GPIO1, GPIO2, GPIO5, GPIO6, GPIO7, GPIO8 в Serial0 (аппаратный UART, не USB CDC синхронизации).
- Калибровка базовых значений без перезагрузки, `$TOUCH_CAL`.
- Регулировка относительных порогов по отдельности и вместе; параметры сохраняются **только до перезагрузки**.
- Для подавления ложной прокрутки: 90 мс непрерывного обнаружения касания перед отслеживанием угла, минимальный ход 0.12 рад, отсечение больших скачков, фильтрация пространственно неоднозначных показаний.
- Удерживаемая механическая кнопка блокирует одновременную прокрутку Touch Wheel.
- Отладочное чтение сенсоров продолжает работать при `$TOUCH_ENABLE=0` и `$DISABLE_HARDWARE_CONTROL=1`.

## Команды через Serial0 115200 (нужен перевод строки)

| Команда | Описание |
| --- | --- |
| `$TOUCH` | Одноразовая сводка и показания всех шести электродов |
| `$TOUCH_DEBUG=1` | Поток показаний раз в ~250 мс и события `TOUCH_EVENT=UP/DOWN` |
| `$TOUCH_DEBUG=0` | Отключить поток |
| `$TOUCH_CAL` | Перекалибровать. **Убрать пальцы с колеса!** |
| `$TOUCH_ENABLE=0` | Отключить только прокрутку колесом, физические кнопки продолжат работать |
| `$TOUCH_ENABLE=1` | Снова включить обработку колеса |
| `$TOUCH_SENS=10` | Порог каждого канала как процент его BASE, диапазон 1–80 (больше = менее чувствительно) |
| `$TOUCH_TOTAL=10` | Суммарный порог относительно среднего BASE, 1–80 процентов |
| `$TOUCH_MIN=5` | Минимальное абсолютное изменение RAW относительно BASE, 1–100000 |
| `$TOUCH_DOM=50` | Требуемая направленность сигнала, 20–95%; больше = меньше ложных касаний, но чувствительность ниже |
| `$TOUCH_PAD=1,15` | Для площадки №1 (GPIO1) установить отдельный относительный порог 15%; номера 1–6 |
| `$TOUCH_PAD=1,0` | Убрать индивидуальную настройку, наследовать общий SENS |
| `$BTNS_ADC=1` | Отладка кнопок GPIO9; помогает понять, виноват touch или резистивная лестница |
| `$BTNS_ADC=0` | Остановить отладку кнопок |

Схема нумерации: 1=GPIO1, 2=GPIO2, 3=GPIO5, 4=GPIO6, 5=GPIO7, 6=GPIO8.

По умолчанию `SENS=10`, `TOTAL=10`, `MIN=5`, `DOM=50` и обработка колеса включена.

**Толкование показаний:** `RAW` — текущий отсчёт; `BASE` — уровень без касания; `DELTA=RAW-BASE` у ESP32-S3. При касании соответствующего электрода ожидается положительная DELTA. Если `DETECT=YES` появляется без касания, снимите сырые значения, затем попробуйте `$TOUCH_CAL` и повышайте SENS/TOTAL. На оригинальной ESP32 знак DELTA нормализован: касание также отображается положительным.

## Быстрая локализация постоянно бегущего курсора

1. `$TOUCH_ENABLE=0` — если самопрокрутка исчезла, неисправность в Touch Wheel или его калибровке.
2. Если прокрутка осталась, запустить `$BTNS_ADC=1`: возможно ADC GPIO9 ложным образом распознаёт PREV (кнопка «вверх»).
3. `$TOUCH_DEBUG=1`, оставить колесо без касания, записать 3–5 строк RAW/BASE/DELTA.
4. `$TOUCH_CAL` с полностью отпущенным колесом, затем касаться по одной из 6 площадок и записать DELTA.
5. Пробовать `$TOUCH_SENS=15`, `$TOUCH_TOTAL=15` (уменьшить чувствительность); если датчик наоборот ничего не видит — `$TOUCH_SENS=5`, `$TOUCH_TOTAL=5`.
6. Если только один электрод шумит, задать ему отдельный порог: например, `$TOUCH_PAD=3,20`.
7. `$TOUCH_DEBUG=0`, `$TOUCH_ENABLE=1` — проверить прокрутку.

Изменения вступают в силу сразу, в NVS не сохраняются. Это намеренно — для поиска устойчивой калибровки перед дальнейшим обновлением прошивки.
