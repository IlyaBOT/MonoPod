# Click wheel — прототип v0.2: усиленное удержание SELECT

Две подвижные печатные детали для предварительной примерки. Единицы — мм.
Кольцо и SELECT версии 0.2 нужно использовать вместе: изменена общая высота
контактных концов всех пяти толкателей.

## Что изменено

| Параметр | v0.1 | v0.2 |
|---|---:|---:|
| Видимая часть SELECT | Ø15 | Ø15 |
| Отверстие кольца | Ø15,6 | Ø15,4 |
| Радиальный зазор, каждая сторона | 0,30 | 0,20 |
| Скрытый буртик SELECT | Ø16,6, со скосом | Ø20, плоский |
| Радиальное перекрытие буртика с отверстием | 0,50 | 2,30 |
| Направляющая длина отверстия | 1,00 | 2,00 |
| Толщина плоского буртика SELECT | — | 0,80 |
| Зазор между буртиком и торцом направляющей | — | 0,30 |
| Глубина колпачков от лица до контакта | 2,60 | 3,40 |
| Расчётная высота с кнопками 0,8 и FR4 1,6 | 5,00 | 5,80 |

Буртик отвечает за удержание от вытягивания через лицевое отверстие.
Направляющая и уменьшенный радиальный зазор ограничивают боковое смещение
и наклон. Направляющая выполнена на изнанке кольца: Ø15,4 внутри, Ø17,8
снаружи, общая длина от лицевой плоскости 2 мм. Она двигается вместе с кольцом.

Большой буртик сам по себе не гарантирует отсутствие качания. Остались
номинальный боковой ход в зазоре и возможность подъёма SELECT примерно на
0,30 мм до упора в направляющую. Это необходимо учитывать вместе с фактическим
ходом кольца, опорой снизу и геометрией корпуса. Пружинный возврат предполагается
от тактовых кнопок. Корпус, неподвижные направляющие и пружинный преднатяг
в этот комплект не входят. Проверки в железе пока нет.

## Файлы для печати

- `stl/wheel_44.stl` — новое кольцо, четыре удлинённых толкателя и центральная
  направляющая. Есть гравировка 0,2 мм.
- `stl/select_15.stl` — SELECT со скрытым плоским буртиком Ø20 × 0,8.
- `stl/wheel_44_plain.stl` — то же кольцо, но без гравировки.
- `stl/select_fit_test.stl` — пробная полоска с тремя отверстиями для подбора
  посадки под конкретную печать; инструкция ниже.

STL ориентированы лицом к столу, контактами вверх. Масштаб 100%, единицы мм.
**Для SELECT нужны поддержки под горизонтальным выступом широкого буртика.**
Выступ составляет 2,5 мм по радиусу. После снятия поддержек очистите опорную
поверхность буртика и проверьте, что она не цепляется за направляющую.
Пробная полоска поддержек не требует. Начальный слой для примерки можно
выбрать 0,1 мм; используйте настройки своего принтера и проверьте траектории
в слайсере. В колпачках нет специально заданной внутренней полости.

Перед большой печатью:

1. Напечатайте SELECT и пробную полоску одинаковым профилем и материалом.
2. Отверстие с одной точкой имеет Ø15,2; с двумя — Ø15,4; с тремя — Ø15,6.
   Длина каждого отверстия 2 мм, как у направляющей. Точки расположены на
   верхней стороне полоски около соответствующего отверстия.
3. Вставляйте SELECT видимой частью Ø15 вперёд. Выберите отверстие, в котором
   кнопка скользит без заедания и имеет приемлемый люфт. Буртик Ø20 остаётся
   снаружи полоски и через отверстия не проходит.
4. Для отверстий Ø15,2 / 15,4 / 15,6 параметр `radial_gap` равен соответственно
   0,10 / 0,20 / 0,30. Начальная модель использует средний вариант 0,20.
5. При необходимости измените параметр, экспортируйте новое кольцо и примерьте
   весь узел. Фактические размеры отверстия и кнопки могут отличаться от CAD.

## Сборка и габариты

Видимое кольцо Ø44, SELECT Ø15, толщина лица кольца 1,0; после гравировки
остаётся 0,8 мм. Скрытый наружный буртик кольца остаётся Ø45,6, буртик SELECT
теперь Ø20. Радиус четырёх боковых кнопок пока принят 16 мм. Диаметр контактных
концов толкателей — 2,4 мм.

SELECT вставляется с изнанки кольца. Затем кольцо устанавливается с внутренней
стороны корпуса, и только после этого ставится плата с пятью кнопками.
Фиксация кольца в корпусе должна удерживать его наружный буртик и допускать
рабочее перемещение. Начальные диаметры корпуса: лицевое отверстие Ø44,6,
пространство под наружный буртик Ø46,2. Посадку по высоте нужно согласовать
с реальным корпусом. Для доступа к снятию поддержек SELECT остаётся отдельной
деталью до сборки.

Плата и корпус должны ограничивать уход деталей внутрь. Удерживающие буртики
сами по себе не превращают две свободные детали в полностью закреплённый узел.
Четыре M2 относятся к неподвижной плате/корпусу, в подвижные детали не добавлены.
Координаты M2 не заданы. Под SELECT необходима опора под пятую кнопку; большое
центральное отверстие платы из исходной иллюстрации для этой конструкции
не подходит без дополнительной площадки.

При принятой высоте кнопок 0,8 мм:

`лицо → контакт 3,4 + кнопка 0,8 + FR4 1,6 = 5,8 мм`.

Это на 0,8 мм выше первой версии. Держатель, крепёж и допуски корпуса сюда
не включены. Если 0,8 мм — только корпус тактовой кнопки, а её привод выше,
размер нужно пересчитать. Реальные высота и ход кнопок пока неизвестны.

Координаты центров кнопок при виде спереди: MENU (0; +16), NEXT (+16; 0),
PLAY (0; −16), PREV (−16; 0), SELECT (0; 0).

## Электроды

Обновлённый `reference/electrodes_1to1.svg` содержит шесть медных секторов с
зазорами 1,2 мм. Внутренний радиус увеличен до 9,5 мм, чтобы освободить место
для направляющей; внешний — 20,8 мм. Возле оснований толкателей вырезы R2,4.
Печатайте 100%, без подгонки под страницу, проверьте отрезок 20 мм. E1–E6 —
надписи бумажного шаблона, не вырезы в меди. Электроника, пайка, прокладка
проводов и работа ёмкостного сенсора не проверены.

## Исходники

`source/clickwheel.scad` — самостоятельный исходник OpenSCAD. Основные размеры
в начале файла. Режимы `print`, `assembled`, `ring`, `select`; F6, Export STL.
Параметр `retention_lips=true` включает и буртики, и направляющую. Отключение
этого параметра убирает разработанное удержание и не является рекомендуемым
вариантом текущей сборки.

`cad/caps_assembly.step` содержит две отдельные твердотельные детали в мм.
Лицевая плоскость Z=0, изнанка в −Z. Отдельные STEP также приложены.

`source/build_model.py` — генератор CadQuery 2.7; нужны `cadquery`, `numpy`,
`matplotlib`. Параметры задаются в `Parameters`; JSON — сохранённый снимок.
`source/make_preview.py` обновляет общий вид. Изменение только SCAD не обновляет
STEP и прочие документы автоматически.

## Проверки

Проверены валидность твёрдых тел, замкнутость и ориентация STL, отсутствие
пересечений колпачков в покое и при пробном раздельном ходе 0,2 мм, четыре
направления покачивания кольца, смещение SELECT на 0,15 мм и подъём до упора.
Отдельная проверка показывает, что дальнейшему прямому вытягиванию на 0,1 мм
после упора мешает материал направляющей. Результаты в
`reference/geometry_check.json`.

Это проверки номинальной геометрии. Они не доказывают прочность пластика,
свободный ход после печати или отсутствие ощутимого люфта. Для окончательной
подгонки нужны конкретные кнопки, плата, принтер и корпус.
