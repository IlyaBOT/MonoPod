# Фотошаблон F.Mask, 31.10.2026

PDF: FMask_NEGATIVE_MATERIAL_A4_MIRRORED_1to1.pdf. A4, строго 1:1, одна страница, две одинаковые копии. Пользователь подтвердил НЕГАТИВНУЮ маску: засвеченное остаётся, незасвеченное смывается.

Чёрные непрозрачные окна совпадают с площадками, где маска не нужна. Прозрачное поле даёт засветить и сохранить остальную маску. Оптически это положительное изображение данных F.Mask; название «негативная» относится к материалу, а не к инверсии картинки.

Установить 100% / Actual Size; не включать Fit/«Вписать», зеркало или инверсию в драйвере. Тип носителя и плотность чернил выбрать по инструкции к струйной плёнке и принтеру. Перед использованием проверить контрольную линию 50 мм и квадрат 10×10 мм. Белое в PDF означает отсутствие чернил, то есть прозрачное место на плёнке. Печатать PDF, а не PNG.

## Ориентация плёнки

Принтер печатает на верхнюю матовую приёмную сторону. Шаблон уже зеркальный: после высыхания отпечатка перевернуть его печатной стороной к PCB. Порядок от лампы: УФ -> гладкая прозрачная сторона -> основа плёнки -> матовый слой с чернилами -> нанесённая паяльная маска -> медь/PCB. При взгляде со стороны УФ служебная надпись TOP / F.Mask над копией читается нормально.

Так толщина основы плёнки исключается из зазора «чернила - маска». Плоский плотный контакт без пузырей уменьшает геометрический подствет; не гарантирует отсутствие ореолов при любой экспозиции или плёнке. Матовое покрытие может рассеивать свет, а чернила и основа имеют свою УФ-прозрачность. Физические результаты не измерялись.

Прямой контакт делать только если он разрешён технологией конкретного состава. Липкая не подсушенная маска может прилипнуть к приёмному слою или испортить чернила. Для некоторых материалов требуется подсушка до состояния пригодности к контактной экспозиции, для других - разделительная УФ-прозрачная плёнка; следовать инструкции маски. Разделительная плёнка увеличивает зазор. Не назначены время/длина волны/температура без названия материала. Чёрный рисунок должен иметь достаточную плотность именно для рабочей УФ-длины волны; проверка видимым светом не измеряет эту плотность.

## Геометрия

Экспортировано из текущей платы с исправленной подписью Chicago Kare. Только F.Mask, без дорожек, шелкографии и контурной линии. Медная надпись не добавляет окна и остаётся под маской. Геометрия платы и маски не изменялась; дополнительное ручное расширение окон не выполнялось. В F.Mask 54 физических окна; 55 записей pads включают совпадающую пару PTH/SMD контакта J1.10. Проверены центры всех площадок и отверстий, в том числе NC pin10. Проверены зеркало, масштаб и цвета окон обеих копий в PDF. DRC: 0 нарушений и 0 незавершённых соединений.

Файл FMask_original_NON_MIRRORED.gts - исходный производственный слой окон, не готовый зеркальный печатный шаблон. FMask_OPENINGS_MIRRORED.svg - векторные чёрные окна для негативного материала. PNG служат только для просмотра. Непечатаемые поля страницы с инструкциями и служебными метками находятся вне круглой PCB; при необходимости обрезать плёнку по внешним угловым меткам, не по площадкам.

Полярность и ориентация: [Laserlab, описание фотошаблонов и типов резиста](https://www.laserlab.com/phototool_type.php), определения и пример слоя solder mask. Пропускание конкретной плёнки/чернил, точность принтера, контакт, экспозиция и проявление остаются UNVERIFIED до пробы на вашем материале.
