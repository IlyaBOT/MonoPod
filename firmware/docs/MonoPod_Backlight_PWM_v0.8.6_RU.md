# MonoPod v0.8.6 — аппаратная регулировка подсветки ST7735S

## Аппаратная ревизия

**Прототип Rev. A:** ESP32-S3 N16R8, модуль ST7735S 1.8″, 160×128, подсветка через отдельный управляемый вход LED/BL. **GPIO15** свободен при `FEATURE_DEV_ENCODER=0` (дополнительный энкодер не используется), обеспечивает PWM LEDC. Встроенный RGB-светодиод ESP32-S3 на GPIO48 не задействуется.

Остальная распиновка не меняется: TFT SCK=12, MOSI=11, CS=10, DC=39, RST=47; SD MISO=13/CS=14; I²S BCK=16/LRCK=17/DIN=18; кнопки ADC9; колесо 1,2,5,6,7,8; пьезо GPIO42; HOLD GPIO21; батарея ADC4; USB D-/D+ = 19/20.

**Вариант подключения, предпочтительный для макета: P-MOSFET на положительном выводе LED/BL** (если этот вывод — отдельный положительный вход подсветки, а питание схемы TFT составляет 3,3 В):

```text
                   +3V3
                     |
                     +------ S (P-MOSFET AO3401A)
                     |             |
                   100 kΩ          D ----------------> TFT LED/BL
                     |             G
GPIO15 ---- 100 Ω ---+-------------+

ESP32-S3 GND ----------------------------------------> TFT GND
ESP32-S3 3V3 ----------------------------------------> TFT VCC
```

- При запуске подтяжка 100 кОм держит затвор на 3,3 В, транзистор закрыт.
- На GPIO15 **LOW = включить**, **HIGH = выключить** (инверсная ШИМ).
- **Прежде чем подключать**, проверь схему конкретного TFT: иногда вывод `LED` уже соединён с VCC на плате, либо подключён к катоду светодиодов; в таком случае схема требует адаптации. Нельзя оставлять альтернативный путь питания подсветки в обход ключа.
- Убедись, что на подсветке есть токоограничивающий резистор/драйвер. Не подавай 5 В на эту цепь и не подключай неизвестный ток LED напрямую к GPIO ESP32-S3.
- Проверь обозначение ножек S/G/D по даташиту именно установленного транзистора, а не по внешнему виду корпуса.

**Альтернативный случай:** если модуль имеет документированный цифровой PWM-вход BL с малым входным током и высоким активным уровнем, допустимо подключить GPIO15 к этому входу и поставить `TFT_BL_ACTIVE_LOW = false`. Это **не** разрешение подключать GPIO напрямую к светодиодам неизвестного потребления.

**Обычный ESP32-WROVER:** `PIN_TFT_BL=-1` по умолчанию, потому что безопасный свободный вывод в существующем жгуте не подтверждён. Работа подсветки в этой аппаратной сборке не меняется до выбора и разводки дополнительного GPIO.

## Настройки прошивки

В `Config.h` для S3:

```cpp
constexpr int8_t PIN_TFT_BL = 15;
constexpr bool TFT_BL_ACTIVE_LOW = true; // P-MOS high-side
constexpr uint32_t TFT_BL_PWM_HZ = 16000;
constexpr uint8_t TFT_BL_PWM_BITS = 10;
constexpr uint16_t TFT_BL_FADE_ON_MS = 250;
constexpr uint16_t TFT_BL_FADE_OFF_MS = 400;
```

В Arduino IDE использовать плату `ESP32S3 Dev Module`, Arduino-ESP32 core 3.x, OPI PSRAM для подтверждённого модуля N16R8. Используется Arduino-ESP32 API `ledcAttach(pin,frequency,resolution)` и `ledcWrite(pin,duty)`; сторонние библиотеки для PWM не нужны. Для пьезы используется другой LEDC-канал.

## Поведение интерфейса

- `Settings > Backlight > Brightness` — нажать **Select**, вращать колесо / Previous / Next по 5%, **Select** для завершения. Диапазон **5–100%** (по умолчанию 75%). Значение записывается в NVS (`blpct`).
- `Settings > Backlight > Timeout` — **Select** переключает `Never, 5, 10, 20, 30, 60 s`. По умолчанию 10 секунд, `Never` означает постоянную подсветку.
- `Home > Backlight` — выключение подсветки вручную с плавным затуханием; следующее нажатие любой рабочей кнопки только будит экран.
- При бездействии питание подсветки плавно уменьшается до 0 без очистки GRAM дисплея. Музыка продолжает играть; буфер UI не теряется.
- При взаимодействии подсветка плавно возвращается к заданной яркости; первый ввод после отключения **только будит экран**, не запускает команды меню.
- В USB/Wi-Fi Sync подсветка удерживается включённой, чтобы предупреждение об извлечении microSD/кабеля оставалось видимым, даже если пользователь не касается колеса.
- Fade не использует `delay()`, вычисляется из `millis()` приблизительно каждые 10 мс; применяется программная кривая плавности + гамма-коррекция яркости. Фактические 250/400 мс — выбранные настройки MonoPod, а не подтверждённые тайминги Apple.
- Wokwi не моделирует транзистор подсветки и PWM, но интерфейс продолжает работать; при таймауте эмулятор закрашивает экран чёрным, как прежде.

## Проверка мультиметром и осциллографом

1. **Без подключённого TFT** включи ESP32-S3: во время начальной загрузки на затворе P-MOSFET должна быть подтяжка к 3,3 В (транзистор выключен).
2. Проверяй осциллографом GPIO15: несущая около **16 кГц**, при затухании скважность плавно меняется. Для инверсной схемы логический HIGH означает выключенную подсветку.
3. Проверь, что TFT LED/BL получает питание только через MOSFET, не связан напрямую с TFT VCC.
4. Подключи экран, измерь максимальный ток подсветки и нагрев транзистора. При заметном мерцании убедись, что драйвер/резистор подсветки рассчитан на PWM.
5. Проверь яркость 5%, 50%, 100%, таймаут, пробуждение с одного ввода и устойчивую подсветку во время USB/Wi-Fi Sync.
6. Проверь влияние PWM на аналоговый звук (шум/свист) и на Touch Wheel. При необходимости разнеси землю силовой подсветки и аналоговой аудиочасти и добавь развязку питания.

**Состояние:** автоматические Python-тесты и нативный тест арифметики fade пройдены. Arduino-ESP32 полная компиляция и фактическая работа LED/BL на этом TFT-модуле не проверены.
