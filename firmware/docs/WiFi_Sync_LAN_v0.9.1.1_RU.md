# MonoPod v0.9.1.1 — Wi-Fi Sync: LAN и резервная AP

## Основной сценарий (домашний Wi-Fi)

1. Подключи ESP32 к домашней Wi-Fi сети через `Settings → Wi-Fi → Wi-Fi Networks`. При повторном включении MonoPod восстанавливает сохранённые credentials из NVS.
2. Убедись, что ESP32 подключилась (индикатор 1–3 полосы).
3. Открой `Settings → Wi-Fi → Start Wi-Fi Sync`.
4. Музыка остановится, интерфейс заблокируется, на экран выйдет SYNC и строка `IP: 192.168.x.y`.
5. Компьютер должен находиться в той же сети; в MonoPod Studio вместо заводского `http://192.168.4.1` укажи `http://192.168.x.y`, взяв IP **с экрана плеера**. Порт 80.
6. Нажми `Connect / Refresh`, затем отправляй треки. Завершай только после окончания передачи длинным Select (или UART `$SELECT_LONG`).

При входе в Sync без подключения к роутеру запускается резервная точка доступа `MonoPod-Sync`. В этом случае подключи компьютер к ней и используй `http://192.168.4.1`.

Без явного `Start Wi-Fi Sync` сервер не работает. `Connection refused` в таком состоянии ожидаем и больше не обозначает неисправность Wi-Fi.

## Лог UART

При подключении через роутер:

```text
[Wi-Fi Sync] LAN HTTP listening at http://192.168.1.123:80
```

При резервной точке доступа:

```text
[Wi-Fi Sync] AP HTTP listening at http://192.168.4.1:80
[Wi-Fi Sync] Connect PC to SSID MonoPod-Sync
```

Если сеть теряется во время LAN Sync, Wi-Fi NetworkManager пытается восстановить соединение. Уже прерванная HTTP-передача может потребовать повторной загрузки: никогда не извлекай карту до завершения/отмены операции.

## Безопасность

HTTP в этой версии **не имеет TLS и аутентификации**. Используй только доверенную локальную сеть; не открывай TCP 80 на маршрутизаторе наружу. Для публикации в чужих/гостевых сетях требуется отдельный механизм авторизации и защиты соединения.

## Проверка

- Wi-Fi STA до Sync: подключён, адрес A.
- После `Start Wi-Fi Sync`: остаётся подключён, адрес A, по `http://A/api/info` должен возвращаться JSON.
- Без Sync: порт 80 закрыт — ожидаемо.
- После `SelectLong`: STA остаётся подключённой, музыка и меню доступны, TCP 80 закрывается.
- Без домашнего Wi-Fi: создаётся `MonoPod-Sync`, `192.168.4.1`.
- Во время HTTP upload выход из Sync заблокирован.

Полная аппаратная проверка на ESP32-S3 и фактическая компиляция Arduino-ESP32 3.3.12 ещё необходимы.
