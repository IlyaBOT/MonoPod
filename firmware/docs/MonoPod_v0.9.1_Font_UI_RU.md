# MonoPod v0.9.1 — шрифты и статус-бар

## Исправлено

1. Заголовки в строке состояния сдвинуты с `y=2` на `y=3` (+1 px вниз). Текстовый индикатор HOLD также смещён на 1 px.
2. Полоски Wi-Fi сдвинуты по вертикали на 1 px вверх. Обновление области иконки без перерисовки всего меню сохранено.
3. Стандартный шрифт перерастеризован из DejaVu Sans Bold с единым базовым уровнем символов. Заменены низкокачественные однобитные таблицы, сохраняется набор из 162 символов, в том числе кириллица.
4. Сглаживание **Font Smoothing: Off/On** теперь применяется как к стандартному шрифту, так и к MPT1-темам. `Off` = бинарный порог alpha 8/15; `On` = четыре бита прозрачности (16 уровней) и RGB565 смешивание. Размеры и позиции глифов между режимами не меняются, а настройка по-прежнему хранится в NVS (`fontAA`).
5. Переключение действует при возвращении в меню, без перезагрузки.

## Сборка и проверка

Установка каких-либо дополнительных шрифтов не требуется: стандартные таблицы уже включены в `MonoFont.h`. Исходный файл TTF не распространяется.

Для необязательной повторной генерации таблиц в `tools/generate_monofont.py` используй установленный DejaVu Sans Bold и Python Pillow:

```powershell
py -m pip install pillow
py tools\generate_monofont.py --font "C:\Windows\Fonts\DejaVuSans-Bold.ttf" --previous "DIY_iPod_Mono\MonoFont.h"
```

**Примечание:** генератор поддерживает формат таблиц как v0.9.0, так и v0.9.1. В обычной сборке перегенерация не требуется.

Тесты: `python -m pytest -q tests`. Для отдельного нативного теста: `g++ -std=c++17 -Itests/stubs -IDIY_iPod_Mono tests/monofont_native_test.cpp -o monofont_test && ./monofont_test`.

Полная Arduino-компиляция и качество на настоящем ST7735S требуют проверки на плате.
