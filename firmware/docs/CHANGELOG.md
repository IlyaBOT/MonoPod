# Изменения прошивки

Здесь только основные пользовательские изменения. Полная история — в коммитах Git.

- **0.10.7.5** — ускорение Wi-Fi Sync и записи на SD, оптимизация CRC32, исправление совместимости с Arduino-ESP32 3.3.12.
- **0.10.7.4** — настройка SPI: экран 20 МГц и карта памяти 16 МГц по умолчанию для ESP32-S3; откат на более медленные частоты при проблемах чтения.
- **0.10.7.3** — дополнительные исправления интерфейса и работы прошивки; [подробный технический отчёт](history/v0.10.7.3_RU.md).
- **0.10.7.2** — экспериментальная защита от пониженного питания и пробуждение переключателем HOLD: [подробности](POWER_GUARD_HOLD_RU.md).
- **0.10.7.1** — пропуск больших встроенных изображений FLAC без изменения исходного файла: [подробности](FLAC_PICTURE_SKIP_RU.md).
- **0.10.7.0** — индекс медиатеки MonoPodDB.
- **0.10.6.x** — потоковое воспроизведение FLAC, изменения аудиобуферов, синхронизации и OTA.

**Примечание:** номера здесь относятся к прошивке. У MonoPod Desktop собственная нумерация версий.
