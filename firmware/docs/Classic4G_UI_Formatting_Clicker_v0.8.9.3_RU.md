# MonoPod v0.8.9.3: экран, настройки, Click Wheel, форматирование

## Эталон интерфейса

Переданный пользователем IPSW `iPod_4.3.1.1.ipsw` — прошивка iPod 4G monochrome (Apple Click Wheel 2004), не iPod 3G. В `manifest.plist`: `FamilyID=4`; внутри бинарника встречаются английские строки `Shuffle Songs`, `Backlight Timer`, `Clicker`, `Reset All Settings`, `About`.

Скриншоты от пользователя и английская таблица строк IPSW расходятся по Backlight Timer: на скриншоте 1/2/3/5 секунд, в IPSW 2/5/10/20. В UI оставлен порядок со скриншота и настройка `Always On`, а не попытка выдать непроверенное меню бинарника за точно воспроизведённое.

**1:1 пиксельную эквивалентность пока не подтверждаем**: необходимы снимки реального экрана после сборки и сравнительный тест шрифтов/отступов. Меню и поведение приведены ближе к эталону; Wi-Fi/BT/SD/яркость и сглаживание добавлены MonoPod.

## Новое меню

Home: `Music`, `Extras`, `Settings`, `Shuffle Songs`, `Backlight`, и `Now Playing` только когда трек запущен.

Settings: `About`, `Shuffle`, `Repeat`, `Backlight Timer`, `Clicker`, `Contrast`, `Brightness`, `Font Smoothing`, `Reset All Settings`, `Wi-Fi`, `Bluetooth` (только ESP32 Classic при FEATURE_BLUETOOTH), `microSD`, `Volume`, `Rescan Music`.

Backlight Timer: Off / 1 / 2 / 3 / 5 Seconds / Always On. Пункт `Brightness` сохранён для PWM-подсветки прототипа. При переключении яркость и режим обновляются немедленно, параметры сохраняются в NVS с небольшой задержкой.

`Reset All Settings`: отдельный экран `Cancel / Reset`, без стирания microSD и сохранённых Wi-Fi credentials (они в отдельном пространстве NVS).

Заголовок статус-бара рассчитывается по фактической ширине символов, выравнивается относительно центра экрана и сокращается `...` при нехватке места. Слева остаётся значок Wi-Fi и HOLD/воспроизведение; справа — батарея.

`About` отображает Songs, Capacity, Available, Version, S/N, Model.

## Форматирование SD

**Предупреждение: полное удаление файлов без возможности восстановления из плеера.** Сделайте бэкап на ПК. Установите библиотеку **SdFat by Bill Greiman v2.x** в Arduino IDE (Library Manager). `FEATURE_SD_FORMAT` теперь включён по умолчанию на физическом устройстве.

Порядок: Settings → microSD → Format Card → Select (первое предупреждение) → Select (окончательное подтверждение). MENU отменяет. Аудио останавливается, Wi-Fi Sync прекращается, карта отключается от Arduino SD, записывается таблица разделов/FS FAT16/32 через SdFat, карта монтируется вновь, создаются `/Music` и `/Playlists`, индекс обновляется. Не вынимайте microSD и не отключайте питание в процессе.

Поскольку Arduino-ESP32 SD.h использует FatFs, форматирование выбрано FAT, а не exFAT. SDXC >32 ГБ форматируется FAT32 не по стандартной рекомендуемой для SDXC файловой системе, чтобы оставаться совместимой с текущей подсистемой чтения. Желательно сначала протестировать с картой 8–32 ГБ. Проводка остается: MOSI GPIO11, SCK GPIO12, MISO GPIO13, CS GPIO14.

`iPod_Control/iTunesDB` не создаётся: это незавершённый отдельный проект совместимости с iTunes.

## Кликер

Короткий «тык» только на события Up/Down (вращение колеса или имитация `$UP`/`$DOWN` в UART). MENU, SELECT, PREV, NEXT не звучат. Для наушников используется краткий затухающий шумовой PCM-импульс; для пьезо — импульс приблизительно 2 мс. Движок после отработки холостого щелчка записывает нули и останавливает I²S. Это предотвращает поддержание DMA после щелчка, однако реальная проверка PCM5102A обязательна.

## Ограничения

Тесты Python и C++ пройдены, но полная компиляция Arduino-ESP32 3.3.12 и аппаратная проверка текущей ветки не выполнялись. Не форматируйте ценную microSD до проверки на запасной карте.
