# MonoPod v0.10.6.8 — FLAC buffer tuned for ESP32-S3 N16R8

- 16 MiB Flash хранит прошивку, OTA разделы и данные, **не** заменяет оперативную память.
- 8 МиБ PSRAM: целевой FLAC compressed ring buffer **2 МиБ**; реальная вместимость зависит от свободной непрерывной памяти.
- Выделение защищено условием `wanted <= free PSRAM / 2`: 2 MiB → 1 MiB → 512 KiB → 256 KiB → 128 KiB, затем при необходимости 32 KiB во внутренней RAM.
- Начальный запрос чтения: только **12 КиБ**, последующее заполнение по **4 КиБ** за проход аудиоцикла; перед началом воспроизведения полное заполнение не требуется.
- 2 МиБ при сжатом битрейте 700–1000 кбит/с — примерно 17–24 сек запаса, **только после заполнения**, не обещание непрерывного реального времени при любом файле.
- Для диагностики при открытии FLAC в UART пишется `FLAC: compressed buffer=... KiB, free PSRAM=... KiB`.
- Core 0 audio task, ST7735 UI на Core 1, 24 × 512 B DMA, Wi-Fi OTA и кнопки/Touch не менялись.
- **Важно:** больше PSRAM не исправляет конфликты на общем SPI; размер буфера снижает вероятность underflow, но увеличение рабочего буфера не ускоряет FLAC-декодирование и не гарантирует устранение треска.
- Arduino IDE: для ESP32-S3 N16R8 нужно включить правильный вариант **OPI PSRAM** и размер Flash 16 MB в Tools; проверить UART `PSRAM=8388608 B (OK)`.

## Проверка

Прогнать `pytest -q tests`, а также нативный тест `g++ -std=c++17 -Itests/fakes tests/flac_ring_native_test.cpp -o /tmp/flac_ring_test && /tmp/flac_ring_test`. Компиляция под ESP32-S3 и физическое тестирование необходимы отдельно.
