# MonoPod v0.10.6 — NEXT 5K1 + S/N compact + conditional Now Playing

Базовая версия и номер прошивки: **0.10.6** (без изменения).

## Изменения
- About: 16-символьный GUID теперь показывается целиком, без `...`; отступ от подписи `S/N` составляет ширину **двух пробелов малого шрифта**.
- Для 16 цифр/букв GUID используется встроенный компактный моноширинный шрифт Adafruit GFX, **6×8 px на символ** вместо 12-px MonoFont. Начало значения — x=38, конец при 16 символах — x=134 (экран 160 px).
- Пункт `Now Playing` последним в главном меню отображается только при `player.active() && !player.paused()`; если музыка остановлена или поставлена на паузу, пункт скрывается. При возобновлении воспроизведения появляется снова. Переход из других меню не прерывает воспроизведение.
- При скрытии пункта выбранная строка автоматически ограничивается последним существующим пунктом.
- Вся остальная логика (резистор NEXT 5,1 кОм, USB MPOD1 v4, BAV3, Wi-Fi) сохранена.

## Проверки
`python3 -m pytest -q tests` — программная регрессия. На настоящей ESP32-S3 и полной Arduino-сборке ещё не проверено.
