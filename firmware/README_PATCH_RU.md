# MonoPod 0.10.1 — ID3 / Now Playing / Wi-Fi one-shot

Основа: `Archive.zip` (переданный пользователем проект 0.10.0). Синхронизация MPOD1 Protocol v4, файловый API, аудиодекодеры и аппаратная распиновка не изменены.

## Что исправлено

- `Id3Parser.h` — новый ограниченный по RAM парсер ID3v2.2, 2.3, 2.4 и fallback ID3v1. Поддерживает Latin-1, UTF-8, UTF-16 с BOM (LE/BE), UTF-16BE, проверку размеров кадров, расширенные заголовки, unsynchronisation для данных текстовых кадров, пропуск недоступных сжатых/зашифрованных кадров, защиту от повреждённых длин.
- Legacy Windows-1251, ошибочно помеченный как Latin-1, распознаётся эвристически при наличии нескольких кириллических букв. Это эвристика, не универсальное распознавание кодировок.
- `Library.cpp` — `MediaLibrary::metadata()` использует новый парсер, не читает обложки целиком; ограничение обрабатываемого текстового кадра 4 КиБ, выделяемых в куче, а не в стеке. Метаданные хранятся UTF-8; вывод может зависеть от наличия символов в шрифте.
- `Display.cpp` — `Now Playing` целиком выводится малым 12-пиксельным шрифтом; стандартная ширина 84 px при доступных 94 px. Остальные заголовки без изменений.
- `WiFiNetworks.cpp` — автоматическое подключение из NVS только один раз после загрузки, таймаут 10 секунд, после ошибки повторных попыток нет. Мигающий Wi-Fi-индикатор выключается. При обрыве установленной сети повторные попытки также отсутствуют. Повторное соединение: через явный выбор сети в меню или после перезапуска. Выход из резервного AP Sync больше не запускает авто-подключение.
- Версия, отображаемая устройством, и HTTP/USB INFO: `0.10.1`, версия синхронизации остаётся **4**.

## Сборка

Откройте `DIY_iPod_Mono/DIY_iPod_Mono.ino` в Arduino IDE или собирайте эту директорию через Arduino CLI. Требуются те же версии ESP32 Core и библиотек, что для 0.10.0.

Для новых метатегов при прошивке нужен **новый индекс**; прошивка при загрузке сканирует карту, а во время Sync можно запустить `SCAN`.

## Известные ограничения

- Необязательные кадры метаданных, например ID3v2 сжатые/зашифрованные, пропускаются.
- При наличии нескольких конкурирующих текстовых полей берётся первое корректное значение.
- Для нестандартного Windows-1251 без метки кодировки используется эвристика; для неоднозначных тегов правильнее сохранить ID3v2.3 UTF-16 или ID3v2.4 UTF-8.
- На TFT должны присутствовать глифы для Unicode-символов; отсутствие глифов шрифта не является ошибкой парсера.
- После выхода из Wi-Fi AP Sync приложение больше не инициирует автоматическое STA-соединение: это сделано намеренно по новому требованию.
