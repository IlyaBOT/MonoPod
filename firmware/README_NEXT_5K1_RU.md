# MonoPod v0.10.6 — NEXT 5K1 hardware adjustment

Это **не новая версия прошивки**: номер остаётся **0.10.6**. Изменена только
калибровка аналоговой резистивной лестницы ESP32-S3 для кнопки NEXT с 4,7 кΩ на 5,1 кΩ.

Ветви кнопок к GND: MENU 0 Ω; PREV 2,2 кΩ; NEXT 5,1 кΩ; PLAY/PAUSE 10 кΩ; SELECT 22 кΩ.
GPIO9 использует INPUT_PULLUP без внешнего общего резистора. Для оригинальной ESP32
(GPIO34 с внешней подтяжкой) значения не изменены.

Условные напряжения при Vcc=3,3 В и внутреннем Rpull≈45 кΩ:
MENU 0 мВ; PREV 154 мВ; NEXT 336 мВ; PLAY/PAUSE 600 мВ; SELECT 1084 мВ.

Новые пороги ESP32-S3 в `DIY_iPod_Mono/Config.h`:
`BUTTON_ADC_BOUNDS_MV = {75, 245, 470, 795, 1550}` мВ.
Прежние: `{75, 235, 450, 795, 1550}` мВ.

Это расчётные, а не откалиброванные по реальному модулю значения. Внутренняя
подтяжка ESP32-S3 имеет разброс. Проверить на плате через диагностический UART0
командой `$BUTTON_ADC` (покоящаяся кнопка и отдельные нажатия).

Остальная прошивка, протокол синхронизации MPOD1 v4 и версия 0.10.6 сохранены.
Для Arduino IDE открыть `DIY_iPod_Mono/DIY_iPod_Mono.ino`.
