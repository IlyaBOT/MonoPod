Нужно создать параметрические 3D-модели корпуса и пробников для проекта MonoPod — DIY плеера в духе раннего monochrome iPod / iPod Classic.

Главная цель сейчас НЕ сделать “идеальный финальный корпус”, а:
1. собрать параметрическую CAD-модель корпуса под текущий прототип,
2. сделать набор пробников / fit-coupons для подбора размеров, зазоров и посадок,
3. подготовить STL/STEP для быстрой печати и проверки.

====================================
КОНТЕКСТ ПРОЕКТА
====================================

Это MonoPod — самодельный музыкальный плеер на ESP32-S3 N16R8.
Нужен корпус, максимально практичный, печатопригодный и модульный, с эстетикой раннего iPod, но без фанатизма: главное сейчас механика, посадки и подбор размеров.

Уже есть:
- 3D-механика Click Wheel в отдельном архиве.
- Фото текущего прототипа.
- Референсы разъёмов и переключателя.
- Известны примерные модули:
  - TFT LCD 1.8" 128x160 SPI (ST7735S типовой модуль),
  - плата зарядки TP4056 USB Type-C, габариты 28 x 17 x 4 мм,
  - миниджек PJ-324M,
  - переключатель HOLD типа SS22F32 (или очень близкий к нему),
  - Click Wheel уже смоделирован и его надо использовать как базовый интерфейс.

Нужно сделать НЕ только финальные детали, но и пробники, потому что точные размеры, реальные допуски принтера и зазоры пока неизвестны.

====================================
ЧТО НУЖНО СДЕЛАТЬ
====================================

Нужно создать параметрическую CAD-систему и экспортировать модели для нескольких деталей:

------------------------------------
1. FRONT PANEL
------------------------------------

Это передняя часть корпуса.

Назначение:
- с лицевой стороны видимая панель,
- изнутри к ней крепится:
  - плата дисплея на 4 винта M2.5,
  - узел Click Wheel на 4 винта M2.5.

Требования:
- Передняя панель должна иметь окно под экран.
- Должна быть круглая / iPod-like зона под click wheel.
- Для Click Wheel использовать уже существующую механику как интерфейс.
- Важно соблюдать интерфейс из README click wheel:
  - отверстия каркаса под M2.5: Ø2.8, квадрат 42 x 42,
  - нужна выборка под кольцо, потому что плоская панель не сядет:
    из README:
    “Опорная плоскость ушей находится на глубине 1.85 мм от лица колеса,
    передний торец кольцевой части каркаса — на глубине 0.70 мм,
    поэтому в будущей панели нужна выборка под кольцо на 1.15 мм
    относительно плоскости опоры ушей.”
- Нужно предусмотреть внутренние стойки / бобышки / посадки под M2.5 для дисплейной платы.
- Дисплейный модуль нужно посадить так, чтобы экран аккуратно выглядывал через окно, с разумной рамкой и без видимых щелей.
- Внешний стиль панели — максимально простой, аккуратный, в духе iPod:
  - мягкие скругления,
  - без лишнего декора,
  - пластик,
  - пригодность к FDM-печати.

Сделать также пробники:
- coupon для окна экрана,
- coupon для посадки click wheel узла во front panel,
- coupon для проверки глубины выборки и совмещения отверстий.

------------------------------------
2. BACK CHASSIS
------------------------------------

Это задняя несущая часть корпуса.

Назначение:
- к ней крепится вся внутренняя начинка / макетная плата с разъёмами,
- она работает как основной структурный “поддон” корпуса.

Требования:
- К ней будет крепиться макетная плата с разъёмами и всем остальным на 3 винта M2 по углам.
- Внизу должен быть вырез / узел под:
  - USB Type-C разъём платы зарядки,
  - миниджек справа от него.
- Type-C должен быть слегка утоплен внутрь корпуса примерно на 0.5–1.0 мм.
- Чтобы не было щелей вокруг Type-C, надо сделать небольшую “юбку” / карман / шахту,
  в которую вставляется сама плата зарядки так, чтобы разъём точно центрировался и выглядел аккуратно.
- Для миниджека PJ-324M нужно сделать панельную установку через гайку:
  структура должна быть примерно такая:
  резьба разъёма | гайка | пластик корпуса | тело разъёма
  или другой вариант, если по геометрии корректнее, но разъём должен надёжно фиксироваться.
- Отверстие и толщина стенки в зоне миниджека должны соответствовать реальной механике PJ-324M.
- Надо сделать место / окно / крепление для переключателя HOLD.
- Для HOLD-переключателя нужно предусмотреть крепление винтами через его боковые отверстия.
- Диаметр крепежа для HOLD оценить как M2 или M2.5, но лучше параметризовать.
- Предусмотреть внутренние плоскости/стойки для крепления макетной платы и запас под проводку.
- Допустить, что это пока прототип, поэтому wiring clearance должен быть щедрым, а не ювелирным.

Сделать также пробники:
- отдельный нижний coupon с Type-C и миниджеком,
- coupon для толщины панели под миниджек и гайку,
- coupon для посадки платы зарядки TP4056 в “юбке”.

------------------------------------
3. DECORATIVE HOLD SLIDER CAP
------------------------------------

Нужна декоративная наружная пластиковая деталь для HOLD, чтобы снаружи торчал не голый чёрный рычажок переключателя, а нормальный внешний ползунок как у оригинального iPod.

Нужна следующая механика:
- В задней крышке / корпусе есть отверстие.
- Снаружи видна декоративная пластиковая накладка-ползунок.
- Эта накладка должна цепляться за рычажок реального переключателя через внутренний паз / зацеп / карман.
- Сам переключатель крепится к корпусу винтами.
- Получается “бутерброд” примерно такого типа:
  винты | переключатель | рычажок переключателя == паз декоративной накладки | отверстие в корпусе | видимая пластиковая часть HOLD-слайдера

Требования:
- Ползунок должен быть удобен для пальца.
- Снаружи он должен визуально напоминать HOLD-слайдер оригинального iPod.
- При этом его нужно реально напечатать на FDM.
- Сделать несколько вариантов зазоров между:
  - отверстием в корпусе,
  - декоративной деталью,
  - реальным рычагом переключателя.
- Нужен отдельный test coupon под этот узел:
  - кусок стенки корпуса,
  - отверстие,
  - декоративный slider cap,
  - посадка под сам переключатель.

------------------------------------
4. ПРОБНИКИ / FIT COUPONS
------------------------------------

Сделай отдельный набор маленьких печатаемых пробников, чтобы не печатать весь корпус каждый раз.

Минимально нужны:
1. Front panel display window coupon
2. Front panel click wheel mount coupon
3. Bottom edge connector coupon:
   - Type-C recess,
   - mini-jack hole,
   - взаимное расположение
4. HOLD switch coupon:
   - отверстие в корпусе,
   - декоративная накладка,
   - крепление переключателя
5. Screw boss coupon:
   - M2.5 под front panel / click wheel,
   - M2 под back chassis,
   - при необходимости несколько вариантов пилотных отверстий
6. Optional tolerance coupon:
   - несколько вариантов зазоров 0.15 / 0.20 / 0.25 / 0.30 мм там, где это критично.

====================================
ВАЖНЫЕ ДАННЫЕ ПО CLICK WHEEL (ИСПОЛЬЗУЙ КАК ОСНОВУ)
====================================

Из архива click wheel использовать как механический интерфейс корпуса:

- Габарит каркаса в плане: 50 x 50 мм
- Осевой размер каркаса: 3.55 мм
- Отверстия каркаса под M2.5: Ø2.8, квадрат 42 x 42
- Видимый диаметр колеса: 44.0 мм
- Видимая Select: 15.0 мм
- Точки крепления к корпусу: ±21 / ±21
- Нужна выборка панели под кольцо click wheel на 1.15 мм относительно плоскости опоры ушей
- Для front panel использовать существующий click wheel frame как основной reference interface

Не ломай уже существующую механику click wheel без очень веской причины.
