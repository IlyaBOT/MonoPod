# Аудит исходников

Первый полный обход `I:\DIY_iPod_Mono` зафиксировал 1869 файлов в `original-inventory.json` (пути, размер, время изменения, SHA-256). В корне нет Git-репозитория: отличия ревизий установлены по содержимому, без утверждения о чистоте относительно неизвестного upstream. `revision-comparison.json` перечисляет изменения модулей между найденными деревьями.

На первом обходе самой поздней основной прошивкой была v0.9.0. Во время реализации появились распакованные v0.9.1 и v0.9.1.1. Проведён второй аудит, исходники и документация новой ветки перенесены на v0.9.1.1. Манифест этой базы и перечень отличий находятся в `baseline-refresh`. Ни один исходный файл v0.9.0 / v0.9.1 / v0.9.1.1 не изменён. Рабочая ветка — отдельная `MonoPod_v0.10.0`.

До v0.10.0 отсутствовали LIST/STAT/READ, произвольные пользовательские каталоги, mkdir/rmdir/rename, USB-темы и расширенная палитра. Desktop требует соответствующих capabilities и не подменяет эти операции локальными данными.

GPIO, AudioEngine, Backlight, Input, схема питания и аппаратные настройки не перерабатывались. Bluetooth Classic по-прежнему исключён препроцессором для S3. Ограничение индекса плеера 2048 не является ограничением файлового менеджера: Desktop читает каталоги страницами и проверен на 2101 записи.


По последнему crash log дополнительно исправлен регресс Library.cpp, унаследованный от v0.9.0. Доказательство из совпадающего ELF и результаты — BOOT_REGRESSION_RU.md. Пользовательский badapple.bav сохранён из v0.9.0; в базе v0.9.1.1 этого файла не было.
