# MonoPod

**MonoPod** — самодельный портативный музыкальный плеер в духе классических iPod. Это одновременно учебный проект и личная разработка: электроника, корпус, прошивка и программа для синхронизации музыки с компьютером.

Плеер построен на **ESP32-S3 N16R8**. У него цветной дисплей ST7735S (160 × 128), сенсорное колесо, физические кнопки, microSD, аудиовыход через PCM5102A и синхронизация по USB или Wi-Fi.

## Быстрый старт

**Прошивка:** откройте [`firmware/DIY_iPod_Mono/DIY_iPod_Mono.ino`](firmware/DIY_iPod_Mono/DIY_iPod_Mono.ino) в Arduino IDE. Список библиотек, настройки платы и важные ограничения приведены в [инструкции прошивки](firmware/README.md).

**Программа для ПК:** откройте [`desktop/MonoPod.Desktop.sln`](desktop/MonoPod.Desktop.sln) в Visual Studio 2022 или соберите через .NET SDK 8. Подробности — в [desktop/README.md](desktop/README.md).

**Корпус и платы:** начните с [hardware/README.md](hardware/README.md).

## Состояние проекта

Разработка продолжается. Поддержка некоторых возможностей зависит от модели ESP32 и выбранной конфигурации. Например, **Bluetooth Classic/A2DP не поддерживается самим ESP32-S3**; соответствующий режим предназначен для оригинального ESP32.

Прошивка и электроника — прототип: перед повседневным использованием необходима проверка питания, зарядки, подключения аккумулятора и поведения при разряде. Архивы старых версий удалены из текущего дерева, но доступны в истории Git.
