# Печатные платы

- [**TDA1308 headphone amplifier**](tda1308-headphone-amp/) — схема, проект KiCad, Gerber и комплект документации для платы усилителя наушников.

**Основная плата MonoPod:** её исходники и производственные чертежи пока отсутствуют в этой папке. Когда они будут найдены, добавляйте их отдельным проектом (например, `hardware/pcb/mainboard/`) вместе со схемой, разводкой, библиотеками и BOM. Не используйте изображения или 3D-макеты из корпуса вместо электрической схемы.
