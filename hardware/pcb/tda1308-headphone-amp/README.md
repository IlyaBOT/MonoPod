# Усилитель наушников TDA1308

Проект платы усилителя для MonoPod в **KiCad**. Файлы для редактирования находятся в этой папке; производственные экспорты вынесены в `gerbers/`.

## Основные файлы

- [`TDA1308_HeadphoneAmp.kicad_sch`](TDA1308_HeadphoneAmp.kicad_sch) — схема.
- [`TDA1308_HeadphoneAmp.kicad_pcb`](TDA1308_HeadphoneAmp.kicad_pcb) — разводка.
- [`TDA1308_HeadphoneAmp.kicad_pro`](TDA1308_HeadphoneAmp.kicad_pro) — параметры проекта.
- [`BOM.csv`](BOM.csv) — список компонентов.
- `libraries/` — библиотеки символов, посадочных мест и моделей, необходимые проекту.
- `gerbers/` — файлы для производства.
- [`TECHNICAL_NOTES_RU.md`](TECHNICAL_NOTES_RU.md) — оригинальная подробная техническая документация, включая ограничения сборки.

**Не заказывайте плату без проверки** электрической схемы, полярности компонентов, посадочных мест и соответствия вашей версии корпуса. Снимки ранних ревизий и старые промежуточные тестовые результаты остаются в истории Git.
