# MonoPod Hardware

Здесь лежат механика и электроника MonoPod. Чертежи — рабочие файлы прототипа; перед изготовлением необходима проверка размеров и электрических соединений.

| Раздел | Что внутри |
| --- | --- |
| [enclosure/](enclosure/) | Корпус, детали для 3D-печати, STEP/STL и лазерные контуры. |
| [pcb/](pcb/) | Проекты печатных плат, схемы, Gerber и BOM. |

**Важно:** пока здесь есть проект платы усилителя на TDA1308, но **полный проект основной платы MonoPod ещё не добавлен**. Исходники KiCad лучше хранить вместе со схемой, библиотеками и производственными файлами; один рендер платы не заменяет проект.

В архиве корпуса оставлены и основные детали, и пробники посадок: они нужны для проверки допусков при печати. Модель не является подтверждением, что реальная сборка уже подходит по размерам.
