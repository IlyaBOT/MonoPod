# Корпус MonoPod v0.8

Основная модель корпуса **83×115×26 мм** объединяет исходники `MonoPod_Korpus_STEP_CadQuery` с правками USB-C и миниджека по примерке от 18.11.2026.

| Передняя панель, рамка, акрил и TFT в сборе | [front_acrylic_display_assembly.step](cad/front_acrylic_display_assembly.step) |
| Передняя панель для печати | [front_panel.stl](stl/front_panel.stl) |
| Рамка дисплея для печати | [display_lens_carrier.stl](stl/display_lens_carrier.stl) |
| Пробник посадки дисплея | [display_window_coupon.stl](stl/display_window_coupon.stl) |

| Нижняя вставка | [bottom_connector_insert.stl](stl/bottom_connector_insert.stl) |
| Пробник нижнего торца | [bottom_edge_coupon.stl](stl/bottom_edge_coupon.stl) |
| Контур акрила 1:1 | [DXF](laser/acrylic_screen_lens_1to1.dxf), [SVG](laser/acrylic_screen_lens_1to1.svg) |

Рамка `display_lens_carrier` соответствует присланной `Ramka`, а пробник `display_window_coupon` соответствует `Probnik`. В модели четыре крепления TFT с шагом **52×30,4 мм**, плата на глубине **6 мм** и винты **M2.5×6**. Бортик рамки толщиной 1 мм заходит под панель на **2 мм**. Ответная ступенька задаёт зазор **0,15 мм** под клей. Рамка устанавливается с тыльной стороны.

Акрил **45×38×1 мм, R2**. Световой проём **38×31 мм** смещён влево на 3 мм от центра креплений. Центр акрила расположен на 2 мм левее и на 1,2 мм выше центра креплений. Номинальный зазор до стекла TFT **0,3 мм**. Перед вклейкой можно проверить края изображения на включённом TFT с собранным пробником. Лазерные контуры заданы в миллиметрах. Компенсация пропила настраивается в CAM по конкретному лазеру.

Вставка рассчитана под компактный поддон v0.8. Ось USB-C сдвинута на **1 мм к миниджеку** и **0,5 мм к лицевой панели**. Карман под корпус кабеля имеет размер **11,5×7,4 мм** и глубину **2,3 мм**. Сквозное окно составляет **9,6×3,8 мм**, перемычка за карманом **0,8 мм**, стенка под гайкой миниджека **1 мм**. Фиксация кабеля и гайки зависит от реальных деталей и печати.

Проверены 58 комплектов STEP/STL, полная сборка, опускание припаянной платы, установка нижней вставки и рамки. Булево сравнение подтвердило совпадение геометрии передней панели, поддона, рамки и пробника с присланными STEP. Проверка светового проёма охватывает габарит видимой области из модели с допуском ±0,5 мм при прямом взгляде. Совместная физическая сборка v0.8 пока не проверена. [Отчёт CAD](validation/integration_check.json)

Для повторной генерации используйте Python 3.12 и зависимости из `source/requirements.txt`. Размеры редактируются в `source/parameters.json`.

```powershell
python -m pip install -r source/requirements.txt
python source/build_enclosure.py
python source/make_laser_files.py
python source/verify_integration.py
```

В `reference/tft_52x30p4` лежат присланные STEP, STL, параметры и исходный генератор дисплейного узла.
