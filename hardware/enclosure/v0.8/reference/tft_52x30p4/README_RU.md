# MonoPod v0.7 · CAD корпуса

Рабочая база корпуса — `0.7-tft-glue`, габарит **83×115×26 мм**. По отзыву после печати рамка дисплея и пробники разъёмов подошли. STEP узла дисплея соответствует комплекту `MonoPod_TFT_Nahlest2_Probnik.zip`. Для нижних разъёмов приложен номинальный вариант из CAD с зазором вставки **0,2 мм**. Вариант, который прошёл примерку, можно определить по STL, отправленному на печать.

| Файл | Назначение |
|---|---|
| `cad/Probnik.step` | Пробник посадки дисплея с четырьмя укороченными стойками |
| `cad/Ramka.step` | Рамка дисплея со сплошным бортиком под клей |
| `cad/front_acrylic_display_assembly.step` | Панель, рамка, акрил и габарит модуля в сборе |
| `cad/Front_Panel.step`, `cad/Back_Chassis.step` | Передняя панель и поддон |
| `cad/Bottom_Edge_Coupon.step`, `cad/Bottom_Connector_Insert.step` | Пробник зоны USB-C и миниджека и номинальная нижняя вставка |
| `cad/assembly_mockup.step` | Сборка корпуса с положениями узлов |
| `source/parameters.json`, `source/build_enclosure.py` | Редактируемые размеры и генератор CadQuery |

## Размеры узла дисплея

- Шаг отверстий **52×30,4 мм**. В параметрах `display.hole_pitch_y` задаёт горизонталь корпуса, а `display.hole_pitch_x` — короткую сторону платы, поскольку модуль повёрнут на 90°.
- Стойки панели и рамки укорочены на **1 мм** относительно предыдущей модели. `display.pcb_front_depth` задаёт глубину передней стороны платы **6 мм** от лица корпуса. Крепёж — четыре M2.5×6.
- Бортик рамки заходит под панель на **2 мм** по контуру. Расчётный зазор для клея **0,15 мм**. Эти размеры задают `lens_carrier.panel_glue_overlap` и `lens_carrier.panel_pocket_axial_clearance`.
- Акрил **45×38×1 мм**. Световой проём **38×31 мм** смещён влево на **3 мм** от центра креплений, чтобы прикрыть шлейф справа. Посадка акрила поднята на **1,2 мм** относительно предыдущей модели для зазора до Click Wheel.

## Пересборка

Распакуйте архив целиком. Из корня комплекта запустите команды с Python 3.13.

```powershell
python -m pip install -r source/requirements.txt
python source/build_enclosure.py --output build
```

Генератор выводит STEP и STL всех деталей и пробников. Пробник дисплея называется `display_window_coupon`, рамка — `display_lens_carrier`. Все размеры в миллиметрах. В `validation/geometry_check.json` сохранены результаты проверки геометрии этой ревизии.
