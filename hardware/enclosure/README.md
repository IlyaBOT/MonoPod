# Корпус MonoPod

Текущая модель корпуса — [**v0.8**](v0.8/README_RU.md). В ней есть рамка TFT с креплениями 52×30,4 мм, акрил 45×38×1 мм и нижняя вставка с уточнёнными посадками USB-C и миниджека.

[Сборка STEP](v0.8/cad/assembly_mockup.step) · [STL для печати](v0.8/stl/) · [Исходники CadQuery](v0.8/source/) · [Лазерные контуры](v0.8/laser/)

Внутри:
- `source/` — параметры и генераторы модели;
- `cad/` — STEP;
- `stl/` — детали для 3D-печати;
- `laser/` — DXF/SVG для акрилового окна;
- `images/` — иллюстрации;
- `reference/` — обмеры, сборки и вспомогательные модели.

Размеры и допуски проверяйте на физических деталях. Пробники посадок не нужно печатать все сразу.

Предыдущий комплект с акриловым окном и карманом для USB-C доступен в [v0.4](v0.4/).
