# Корпус MonoPod

Текущий набор: [**v0.4 — USB-C и акриловое окно дисплея**](v0.4/).

Внутри:
- `source/` — параметры и генераторы модели;
- `cad/` — STEP;
- `stl/` — детали для 3D-печати;
- `laser/` — DXF/SVG для акрилового окна;
- `images/` — иллюстрации;
- `reference/` — обмеры, сборки и вспомогательные модели.

Размеры и допуски проверяйте на физических деталях. Пробники посадок не нужно печатать все сразу.
